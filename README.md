# AceAdvice - IT Consulting Website

A modern, responsive static website for an IT consulting company. The website showcases services, team members, and provides a contact form for potential clients.

## Features

- Responsive design that works on all devices
- Modern and clean user interface
- Smooth scrolling navigation
- Interactive service cards
- Contact form with validation
- Mobile-friendly navigation
- Animated sections on scroll
- Social media integration

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)
- Font Awesome Icons
- Google Fonts (Poppins)

## Setup Instructions

1. Clone the repository:
```bash
git clone https://github.com/yourusername/aceadvice.git
```

2. Navigate to the project directory:
```bash
cd aceadvice
```

3. Open the website:
   - Double click on `index.html` to open in your default browser
   - Or use a local server (recommended):
     ```bash
     # Using Python 3
     python -m http.server 8000
     
     # Using Node.js
     npx serve
     ```

4. Visit `http://localhost:8000` in your browser

## Customization

- To change the company name, edit the `<title>` tag and logo in `index.html`
- To modify colors, edit the CSS variables in `styles.css`
- To add/remove services, edit the services section in `index.html`
- To update team members, modify the team section in `index.html`
- To change contact information, update the contact section in `index.html`
